# DEAD LETTER asset guide

이 폴더는 실제 게임 제작에 사용하는 프로젝트 전용 에셋의 기준 위치입니다.

| 폴더 | 용도 | 주 담당 |
| --- | --- | --- |
| `Art` | 모델과 원본 텍스처 | 환경/캐릭터 아트 |
| `Audio` | 음악, 환경음, 효과음 | 사운드 |
| `Materials` | 게임 공용 머티리얼 | 환경 아트 |
| `Prefabs/Environment` | 벽, 문, 가구 등 맵용 프리팹 | 맵 제작자 |
| `Prefabs/Interactables` | 문, 컴퓨터, 편지 등 상호작용 프리팹 | 프로그래밍/레벨 디자인 |
| `Scenes/Maps/Incoming` | 친구가 전달하는 원본 맵 | 맵 제작자 |
| `Scenes/Maps/Integrated` | 검수가 끝난 통합 맵 | 프로젝트 담당자 |
| `Scenes/Gameplay` | 실제 빌드에 사용하는 게임 씬 | 프로젝트 담당자 |
| `Scenes/Sandbox` | 개인 실험과 임시 테스트 | 누구나 |
| `Scripts` | 런타임 및 에디터 코드 | 프로그래밍 |

`Assets/Scenes/SampleScene.unity`는 현재 개발 중인 기존 맵을 보존하기 위해 당분간 그대로 둡니다. 새로 전달받는 맵은 이 파일을 덮어쓰지 않습니다.
